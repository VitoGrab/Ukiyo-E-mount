# Ukiyo-E-mount v0.5.0 — standalone camera-powered prototype

**Development preview.** Core prime-lens firmware milestone for XIAO SAMD21 and Sony a6000. Not a finished or electrically qualified hardware product.

## Changes since v0.4.11 (historically v0.411)

- Functional camera-only power from contact 5 (LOGIC_VCC) to XIAO 3V3, retaining the existing A0 divider and XDETECT circuit.
- SAMD21 IDLE0 sleep in the fully suspended protocol state, with the existing BODY_CS interrupt and short wake preserved.
- Software-controlled LEDs extinguish during sleep; production mode disables them throughout.
- Supply-loss ADC diagnostics and passive sampling while stopped.
- USB profile programming works with direct-power wiring: stopped bus and active CDC remain required, but A0 is no longer a programming interlock. The picker uses terminal-height pagination and [y/N] detachment confirmation. Verified uploads leave the bus OFF until the next camera-powered boot.
- Firmware identity v0.5.0 (expected Sony version Ver.05.000); protocol revision 1.08 and v1 prime profile format unchanged.

## Evidence and limits

Maintainer-reported a6000 tests on the pre-release firmware: camera-only startup, lens recognition, off/on remount, live lens exchange, sleep and near-immediate half-press wake with LEDs restored. Approximate rail readings: 3.2 V active and 3.06–3.1 V suspended. See [Stage 5 evidence](../STAGE5_CAMERA_POWER_POC.md). Earlier v0.411 tests established persistent prime profiles and EXIF behavior.

The final profile-maintenance correction, version-label build, production hardware regression, quantified power savings, startup current/transient margin, reverse-current protection, endurance, other camera bodies and integrated mechanical design remain unverified. Do not simultaneously connect USB and the direct camera supply; detach the camera physically for firmware/profile programming. This release is a prototype milestone, not a finished adapter.

## Next

Manual zoom profiles (#5), then systematic cross-body compatibility. Hardware integration proceeds in parallel with separately purchased SELP1650 service contact assemblies. No undervoltage LED or deeper sleep feature is planned for this milestone.
