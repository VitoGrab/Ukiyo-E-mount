# Ukiyo-E-mount v0.411 — persistent prime-lens profiles

**Development preview / externally powered prototype.** This is the frozen firmware baseline before Stage 5 (camera-rail power). Tested on Seeed Studio XIAO SAMD21 and Sony a6000; not a finished camera-powered adapter.

## Highlights

- Native manual-focus Sony E-mount emulation at negotiated 1.5 Mbaud; focus peaking, focus magnification and EXIF lens metadata.
- Body-driven handshake, shutdown, short wake and reinitialization with optional USB diagnostics.
- Single universal firmware with an independent 559-byte versioned binary lens profile, CRC32 validation and embedded Helios fallback.
- Catalog of 16 supported prime lenses and four reserved zoom entries; zoom profiles are not yet generated or supported.
- 8 KiB reserved Flash region, guarded USB CDC profile programming, byte-for-byte readback and automatic MCU reset/re-arm.
- BOSSA 1.9 with explicit 0x2000 application offset and row-local erase, retaining the programmed profile during firmware updates.
- Consolidated VS Code tasks: Build & Upload, Select Build Type, Upload Lens Profile, Monitor and Clean.

## Validated hardware behavior

Maintainer-reported tests on a6000 include Helios/Hanimex metadata switching and aperture range, Pentacon profile programming and reset, and Rubinar fixed f/5.6 aperture. A changed 41900-byte firmware image passed BOSSA 1.9 write and verification, with the Hanimex profile remaining valid. See [hardware evidence](../PROFILE_FLASH.md#bossa-19-and-automatic-reset-hardware-acceptance) and [lens profile evidence](../LENS_PROFILES.md#hardware-evidence-2026-11-27).

## Getting started

Use the XIAO SAMD21 board and the documented externally powered development wiring. Build and upload from source using PlatformIO and the `Ukiyo: Build & Upload` task. For profile programming, physically disconnect the camera, connect XIAO by USB, and use `Ukiyo: Upload Lens Profile`. Do not directly connect camera power rails to the board based on this release.

## Known limitations

- Camera-rail supply, absolute cold-start timing, backfeed protection and mechanical integration are not yet validated.
- Additional bodies, production-environment hardware regression, interrupted profile writes and the complete post-refactor host suite remain open.
- Intermittent firmware/protocol MakerNotes ([#3](https://github.com/VitoGrab/Ukiyo-E-mount/issues/3)) and manual zoom support ([#5](https://github.com/VitoGrab/Ukiyo-E-mount/issues/5)) remain open.
- Only one active external profile is stored. Profile CRC is not authentication. A failed write can fall back to the embedded profile.
- This is a source release; no independently verified release firmware binary is attached.
